## 1. 概述

【公司全称】（以下简称"我们"）通过 **LivePulse 脉播**（livepulse.app，下称"本服务"）
为直播带货主播、MCN 机构提供 AI 驱动的直播录屏分析与跨场进步追踪服务。

我们高度重视您的隐私。本《隐私政策》说明我们收集哪些信息、如何使用、如何保护，
以及您对自己信息所拥有的权利。

**适用范围**：本政策适用于您使用本服务的全部行为，包括通过 web 网页端、移动 H5、
任何形式的 API 接入。

**关键摘要**（不替代下方完整条款）：
- 我们存储您上传的直播录屏视频、文字转写、弹幕数据，用于生成分析报告
- 我们调用阿里云 OCR / ASR 处理视频，**视频数据会进入阿里云服务器**
- 我们存储您的账号信息（邮箱 / 手机号），用于登录与重要通知
- 我们**不会**将您的视频内容卖给任何第三方
- 您可以随时导出、删除自己的全部数据

## 2. 我们收集的信息

### 2.1 账户信息

| 字段 | 是否必需 | 用途 |
|------|---------|------|
| 邮箱地址 | 是（与手机号二选一） | 登录、找回密码、重要通知 |
| 手机号码 | 是（与邮箱二选一） | 登录、短信验证码 |
| 加密密码 hash | 是（如使用密码登录） | 身份验证 |
| 微信 / 抖音 OpenID | 否（如使用 OAuth） | 第三方登录绑定 |
| 邀请码 | 是（内测期） | 注册资格验证 |
| 主播名称 / MCN 名称 | 否 | 报告分组与展示 |

### 2.2 您主动上传的内容

- **直播录屏视频文件**（mp4/flv 等）
- **手动添加的笔记 / 复盘评注**
- **主播档案信息**（您填写的展示用昵称、平台、粉丝数等）

### 2.3 通过分析自动生成的数据

为生成分析报告，我们对您上传的视频运行如下处理流程：

| 处理类型 | 产生的数据 | 存储期 |
|---------|-----------|--------|
| ASR 语音转写 | 主播话术文本 + 时间戳 | 同视频 |
| OCR 弹幕识别 | 弹幕文本 + 用户名 + 时间戳 | 同视频 |
| 意图分类 / 战术分析 | 段落标签（购买意图 / 逼单 / 讲解等） | 同视频 |
| 评分计算 | 综合分、互动分、转化分、内容分 | 同视频 |
| AI 选段评价（按需） | 调用 Claude / Qwen 生成的文字点评 | 同视频 |

### 2.4 设备与访问日志

| 字段 | 用途 |
|------|------|
| IP 地址 | 安全审计、地域统计、限流防滥用 |
| 浏览器 User-Agent | 兼容性诊断、安全审计 |
| 访问时间 | 安全审计 |
| 上传 / 下载流量 | 用量配额与计费 |

### 2.5 Cookie 与本地存储

我们使用以下类型的本地存储：

| 类型 | 用途 | 可否禁用 |
|------|------|---------|
| 会话 Token（JWT） | 保持登录状态 | 否（禁用即无法使用） |
| 错误诊断（Sentry） | 自动上报前端崩溃 | 通过浏览器禁用 |

我们**不使用**广告追踪 cookie、跨站行为分析 cookie。

## 3. 我们如何使用您的信息

我们仅在以下场景使用上述信息：

1. **提供核心服务**：分析直播录屏、生成报告、跨场进步追踪
2. **账户管理**：登录、密码重置、安全提醒
3. **服务改进**：基于**匿名聚合统计**（不针对个人）优化算法、修复缺陷
4. **法律合规**：依据法律法规要求保留必要日志、配合监管查询
5. **重要通知**：服务条款变更、安全事件告知

**我们绝不**：
- 将您的视频或分析报告内容卖给第三方
- 用您的视频训练公开模型
- 在未脱敏的情况下用您的视频做产品 demo
- 通过 cookie 或像素追踪您在其他网站的浏览行为

## 4. 我们与谁共享您的信息 🔍

### 4.1 第三方服务提供商（数据处理者）

为提供本服务，我们必须将部分数据发送给以下处理者：

| 服务商 | 共享内容 | 用途 | 数据所在地 |
|--------|---------|------|----------|

| **Sentry**（错误追踪） | 异常堆栈、用户 ID | 前后端故障诊断 | 全球（视您所在地路由） |
| **【支付服务商】**（M2 启用） | 订单金额、支付状态 | 收款与发票 | 中国大陆 |

**🔍 数据出境提示**：使用 Anthropic Claude 处理选段评价时，**该段文字内容会传输至美国**。
如您不接受数据出境，可以：
- 不使用 AI Range Analysis 功能（核心分析仍可用）
- 等待我们提供国内大模型默认开关（已支持，settings 切换 LLM_PROVIDER=qwen 即可）

- 防止重大欺诈或安全事件

任何此类披露**都会有内部记录**，必要时我们会在法律允许的范围内通知您。

### 4.3 业务转让

若我们发生合并、收购、资产转让等情形，您的信息可能作为资产之一转移。
转移前我们会通过站内通知、邮件等方式告知您，您有权选择删除账户。

## 5. 数据存储与安全

### 5.1 存储位置

- **账户与分析报告**：中国香港【或华东，备案后】阿里云 ECS
- **视频原始文件**：阿里云 OSS（中国）
- **数据库备份**：每日加密快照，保留 30 天

### 5.2 安全措施

| 维度 | 我们做了什么 |
|------|-------------|
| 传输 | 全站 HTTPS（TLS 1.2+），HSTS 强制 |
| 存储 | 数据库密码 argon2 哈希；秘钥经环境变量注入，不入代码库 |
| 访问控制 | 多租户严格隔离（数据库 owner_user_id 列级保护 + invariant 测试守护） |
| 审计 | 关键操作（登录、删除、导出）保留日志 |
| 漏洞响应 | 接收 security@【域名】.com 报告，72 小时内确认 |

### 5.3 数据保留期限

| 数据类型 | 默认保留 | 注销账户后 |
|---------|---------|----------|
| 账户信息 | 直到您注销 | 立即删除，匿名化登录日志 |
| 视频文件 | 12 个月（自上传起） | 注销后 30 天内彻底删除 |
| 分析报告 | 与视频同 | 同上 |
| 笔记 | 与视频同 | 同上 |
| 安全审计日志 | 6 个月 | 匿名化保留，仅留时间戳与事件类型 |
| 备份快照 | 30 天滚动 | 加密快照中的数据将在 30 天内过期 |

**12 个月后自动删除**：到期前 30 天我们会站内通知 + 邮件提醒，您可主动续期或导出。

## 6. 您的权利 🔍

依据《个人信息保护法》第四章，您对自己的个人信息享有以下权利：

### 6.1 查询与复制

- 通过【账户中心】→「我的数据」可随时查看我们持有您的全部信息
- 可一键导出 JSON / CSV 格式包

### 6.2 更正与补充

- 账户信息、主播档案：自助修改
- 分析结果如有事实性错误：联系 support@【域名】.com，5 个工作日内处理

### 6.3 删除

- **删除单场视频**：在 session 详情页操作
- **删除主播档案**：删除主播会级联删除其所有 session
- **注销账户**：【账户中心】→「注销账户」一键完成
  - 注销后 30 天内：可恢复（联系客服）
  - 30 天后：所有数据物理删除，无法恢复
  - 法律法规要求保留的日志（如金融账单 6 年）按法定期限保留

### 6.4 撤回同意

您可以随时撤回对以下事项的同意：
- 数据出境（停用 AI Range Analysis 即可）
- 营销邮件接收（每封邮件底部「取消订阅」）
- Cookie（浏览器设置中清理）

撤回不影响撤回前基于您同意已进行的处理活动的效力。

### 6.5 投诉与举报

如您认为我们未妥善处理您的个人信息：
- 第一时间联系：privacy@【域名】.com
- 我们将在 15 个工作日内书面回复
- 如对回复不满，您有权向所在地网信办或法院投诉

## 附录 A：算法说明（参照《互联网信息服务算法推荐管理规定》） 🔍

本服务使用以下算法对您的数据进行处理：

| 算法 | 用途 | 是否使用您的个人信息 |
|------|------|-------------------|
| OCR 文字识别 | 从视频帧提取弹幕、UI 文字 | 是（视频帧含画面） |

| AI 选段评价 | 文字点评生成 | 是（仅段落文本，脱敏） |

**重要说明**：
- 本服务**不向您推荐内容**，也**不基于您的画像做定向营销**
- 评分公式公开透明，可在【docs.livepulse.app/scoring】查阅
- 所有 AI 评价都标注信息来源（哪一段视频、哪一条话术）
